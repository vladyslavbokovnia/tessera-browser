# Tessera Browser

Вертикальный браузер на Electron для Linux на телефоне (Tessera, Debian в PRoot/chroot, X11).

- профили (раздельные сессии), вкладки с миниатюрами
- юзерскрипты в формате Tampermonkey (GM_*), папка `~/.config/tessera-browser/userscripts`
- свой интерфейс: логотипы вместо текста, центральная кнопка-хаб с веером действий
- озвучка (espeak-ng): касание / долгое нажатие, как в модулях универсального приложения
- мобильное окно: без меню рабочего стола (Файл / Правка / Вид), по умолчанию развёрнуто на весь экран X11

Есть два режима запуска:

| Режим | Что нужно | Что получается |
|-------|-----------|----------------|
| Веб (`web.sh`) | только `node` | интерфейс открывается в обычном браузере телефона по локальному адресу; сайты — макет |
| Полный (`run.sh`) | `node`, `npm`, Electron | настоящий браузинг: страницы, профили, юзерскрипты, озвучка espeak-ng |

## Установка и запуск: веб-режим (без Electron)

```bash
sudo apt install git nodejs
git clone https://github.com/vladyslavbokovnia/tessera-browser
cd tessera-browser
bash web.sh          # порт по умолчанию 8780, свой: bash web.sh 9000
```

Открой в браузере телефона `http://127.0.0.1:8780`. С другого устройства в той же сети: `http://<адрес-телефона>:8780`.

Сервер слушает все интерфейсы (`0.0.0.0`), поэтому в чужой сети запускай его осторожно: интерфейс доступен любому, кто знает адрес.

В веб-режиме состояние (вкладки, закладки, профили) живёт в странице и сбрасывается при перезагрузке. Настоящая загрузка сайтов, юзерскрипты и озвучка espeak-ng пока работают только в Electron.

## Установка и запуск: полный режим (Electron)

```bash
sudo apt install git nodejs npm espeak-ng
git clone https://github.com/vladyslavbokovnia/tessera-browser
cd tessera-browser
npm install
./run.sh
```

Для сенсорного экрана удобно: `TB_SCALE=2.5 TB_FRAMELESS=1 ./run.sh` (крупный интерфейс, окно без рамки).

## Обновление

```bash
cd tessera-browser
./update.sh
```

`update.sh` делает `git pull`, закрывает старое окно (в браузере включён запрет второго экземпляра) и запускает заново.

## Переменные запуска

`TB_SCALE=2.5` масштаб интерфейса, `TB_NO_GPU=1`, `TB_WINDOWED=1` обычное окно вместо развёрнутого, `TB_MAXIMIZE=1`, `TB_FULLSCREEN=1`, `TB_FRAMELESS=1`, `TB_DATA=путь` (только для `run.sh`). Для `web.sh` порт задаётся аргументом или `PORT=9000`.

## Жесты

Режим озвучки переключается кнопкой динамика: 0 выкл; 1 касание озвучивает, долгое нажатие действует; 2 действие + голос. Двойной тап по карточке вкладки закрывает её, долгое открывает действия.
